## 🚀 Acerca del Proyecto

**DuckStore** es una tienda en línea enfocada en optimizar el flujo de trabajo tanto para clientes como para administradores. Implementa buenas prácticas de desarrollo, una arquitectura limpia y una interfaz responsive pensada para cualquier dispositivo.

---

## ✨ Características Principales

* 🛒 **Catálogo de Productos:** Exploración, filtrado y búsqueda en tiempo real.
* 📱 **Diseño Responsive:** Experiencia optimizada para móviles, tablets y escritorio.
* 🧑🏻‍💻 **Página de contacto** Atención personalizada en caso de dudas o problemas.
